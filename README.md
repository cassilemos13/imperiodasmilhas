# ✈️ Meu Segundo Cérebro: Milhas Aéreas

## 1. Tema e objetivo

**Tema:** Milhas Aéreas: estratégias de acúmulo, programas de fidelidade e emissão de passagens.

**Objetivo:**

Criar um notebook especialista em milhas aéreas para centralizar conhecimentos, pesquisar fontes confiáveis e aprender estratégias para acumular, administrar e utilizar milhas de maneira inteligente.

O objetivo é compreender como aproveitar melhor os programas de fidelidade e identificar oportunidades para economizar em viagens, sem aumentar os gastos do dia a dia.

## 2. Fontes utilizadas

O notebook foi construído a partir de 18 fontes, conforme indicado pelo Studio, incluindo conteúdos de diferentes formatos:

- Artigos e materiais educativos sobre milhas aéreas.
- Conteúdos sobre programas de fidelidade, como Smiles, LATAM Pass e Azul.
- Vídeos e entrevistas com especialistas do mercado, incluindo Erik Galdino.
- Materiais sobre acúmulo, transferência, validade e emissão de passagens.
- Conteúdos sobre programas de pontos, como Livelo.

**Critério de seleção:**

Foram reunidos conteúdos de programas de fidelidade, plataformas especializadas, materiais educativos e entrevistas para permitir diferentes perspectivas sobre o mercado de milhas.

As informações sobre regras, validade e condições dos programas devem ser conferidas nos canais oficiais, pois podem mudar.

## 3. Diretriz de comportamento do notebook

O notebook foi criado para atuar como um especialista em milhas aéreas, utilizando as fontes adicionadas como base para suas respostas.

A proposta é organizar o conhecimento, explicar conceitos de maneira clara, apresentar estratégias práticas e indicar as fontes utilizadas nas respostas.

## 4. Perguntas e respostas realizadas

### Pergunta 1

**Pergunta:**

Quais são as melhores estratégias para acumular milhas no dia a dia sem gastar mais?

**Resposta:**

O notebook apresentou o conceito de acúmulo orgânico, que consiste em aproveitar os gastos que já seriam realizados para gerar pontos, sem aumentar as despesas.

Uma das estratégias apresentadas foi concentrar os gastos no cartão de crédito, aproveitando os programas de recompensas.
